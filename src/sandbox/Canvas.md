# Canvas

A canvas is an endless board. The file `Example.canvas` next to this note is one: open it from the explorer.

On a canvas you can

- add cards with text, notes, pictures, web pages or code;
- join cards with links and choose how a link ends;
- group cards and move them together;
- draw by hand with `Alt+D`; a short pause at the end of a stroke straightens the shape.

A canvas is stored as plain JSON, so it stays readable and works with version control.
