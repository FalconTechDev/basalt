# Code and the terminal

Code blocks get a run button. Try this one:

```python
for i in range(1, 6):
    print(i, i * i)
```

Runs are limited to 15 seconds and happen in a separate process.

## Files with code

Open a `.py`, `.js` or `.rs` file and press `F5` to run it. Folders with code can be shown in the **Files** and **Code** graphs.

## Terminal

The terminal opens in a tab, under the editor, or on a canvas card. It starts in the vault folder.
