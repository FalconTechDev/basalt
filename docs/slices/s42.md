## Pre-existing breakages fixed so the build works

`node build-app.mjs` failed on a clean checkout of main for two reasons unrelated
to this slice; both were merge artifacts and are fixed in `src-app/manifest.json`:

1. **Stale `patches` entry** — the s32 "P5 patch" (`find` = inherited ES5
   `P5=function(e){...}` text) could never match again after s33 replaced `P5`
   wholesale with `defineS33CanvasFileNode`. Removed the dead patch object.
2. **Duplicate `Oz`/`Nz`/`Bz` claims** — each was claimed twice: once as an s07
   `declarators` entry and once as an s22 `classes` entry. The `classes`
   mechanism is the correct one here (s22's `defineWorkerChannel(host)` needs
   `__basaltHost`), so the three stale s07 declarator entries were removed.
   `node build-app.mjs --check` now passes deterministically.
