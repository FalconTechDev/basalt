- `p2`, `d2` (`var = null`) intentionally left inherited — no observable behaviour.

  behaviour), `pushViewStackHistory` records the *previous* page, `commitPageLoad` compares the

  response `arrayBuffer` through unchanged (same thenable semantics as the original).

  only internal names changed — view types, command ids, DOM classes, i18n keys and the
  `webviewer:update-history` workspace event are identical.
