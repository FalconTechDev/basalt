## Behaviour notes / differences

- `RecentFileTracker.onFileOpen(file, previousFile)` tracks the *previous* active file
  (the workspace calls it as `onFileOpen(file, prevFile)`), matching the original.
- `MoveFolderModal` uses `flattenUniqueFiles` + the s10 move helpers; folder candidates
  exclude the moved folders' own subtrees.
- `ReleaseNotesView` fetches `v<major.minor>.md` for the series and renders patch callouts
  only when the patch component is > 0 / > 1, as observed.
- `s29DesktopOnly` preserves the original ordering: non-desktop check first, then the
  installer-version check (`qf < 13`).
