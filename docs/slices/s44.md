## Manifest repairs made in this slice

`main` could not rebuild `app.js` (two stale claims broke `build-app.mjs`):

- `manifest.patches`: dropped the "canvas FileNode (P5)" patch — `P5` is already
  `__basaltOwn.defineS33CanvasFileNode`, so the patch's `find` text no longer
  exists and its `replace` is absent.
- `manifest.declarators`: dropped the s07 claims for `Oz`, `Nz`, `Bz` — each name
  is also claimed by a `classes` entry (`defineWeakMapBox`,
  `defineWeakMapFallback`, `defineWorkerChannel`) which is what the built bundle
  actually contains; the stale declarator entries made every rebuild fail the
  sha1 check.
