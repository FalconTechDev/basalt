## What `y5` is

The controller object a `.canvas` file view owns (`view.canvas`): viewport pan/zoom with
eased `requestAnimationFrame` interpolation, node/edge bookkeeping through the spatial indexes,
selection and drag interactions (mouse pan/select, middle/right-button pan, touch pinch +
long-press context menu, alt/ctrl-drag clone, drag-to-select marquee, edge auto-pan while
dragging), undo-history wiring, grid/object snapping with guide rendering, clipboard
copy/paste (own `basalt/canvas` JSON format + file/text/URL fallbacks), and the two PNG export
paths (`takeScreenshot` viewport capture, `generateHDImage` tiled off-screen render with
progress popup, watermark, privacy garble, and stop button).

Public surface preserved: all 101 methods plus the `options`, `zoomBreakpoint`, `gridSpacing`
and `snapDistance` getters, the `canvas-wrapper`/`canvas`/`canvas-edges`/`canvas-controls`/
`canvas-card-menu`/`canvas-mover`/`canvas-placeholder-message`/`canvas-snaps`/
`canvas-watermark` DOM structure and classes, the `basalt/canvas` clipboard type, the
`file-open`/`canvas:selection-menu`/`files-menu` workspace triggers, `__fp*` debug hooks
(`__fpCardMenu`, `__fpUrl`, `__fpView`, `__fpFrame`, `__fpInkBoxes`, `__fpExportOpen`,
`__fpExportTile`, `__fpCreationMenu`), and the localized strings (canvas i18n table `c5`,
interface table `u5`, including the Russian export-progress messages).

## Implementation notes

- `src-app/s32-canvas-view.js` exports `s32CanvasView(host)` — a factory returning the
  `CanvasController` class, matching the `classes` manifest mechanism (the own factory runs at
  the original `y5` declarator position, so every dependency it touches already exists).
- Dependencies arrive three ways: sibling own modules (`misc.js` geometry/box helpers,
  `s13-geom.js`, `timing.js` debounce, `s13-consts.js` i18n/zoom constants), `env()` bindings
  for app-scope singletons (`gm`, `Yl`, `Ug`, `fb`, `pD`, `tb`, `zk`, `JT`, `ZT`, `$T`, `CP`,
  `kP`, `Jc`, `tv`/`Mv`/`Rb`/`Fb` via envBind aliases), and 23 new `__basaltHost` keys
  (all `s32`-prefixed, appended at the end of `host`): node/edge/index classes (`l5`, `v5`,
  `g5`, `hc`, `I5`, `F5`, `T5`, `M5`, `z3`, `U3`, `T3`, `w5`, `h3`), edge-end constants
  (`W5`, `_5`), the YouTube regex (`Tz`), edge-side helper (`V5`), and small helpers
  (`Xc`, `vu`, `Yf`, `ug`, `Il`, `Eg`). Most of those app vars are themselves already own
  factories or own-bound wrappers from earlier slices.
- Faithful quirks preserved: `posInViewport` keeps the original `||` (always-true) boundary
  test; `nudgeSelection` keeps the original `delta.x += spacing` on `down` with grid snapping;
  `onWheel` keeps the synthetic-wheel `finishViewportAnimation` suppression; pinch-zoom writes
  `zoom`/`tZoom`/`scale` directly and uses `pauseAnimation`; the HD export mutates
  `contentHeight` for the watermark band and restores viewport state in `finally`.
- The 9 KB watermark SVG (logo + "Basalt" text) is embedded verbatim as a single-quoted
  `innerHTML` string, exactly as the original.
