manifest claims survived later own-class replacements and made every rebuild
throw.

  never match — `P5` is now `__basaltOwn.defineS33CanvasFileNode(__basaltHost)`
  (slice s33). Removed.

  (`s07weakMapBox` / `s07weakMapPolyfill` / `s07workerBridge()`) and once by s22
  as `classes` (`defineWeakMapBox` / `defineWeakMapFallback` /
  `defineWorkerChannel`). The s22 class replacements are the live ones; the s07
  declarator duplicates were dropped. The resulting manifest is semantically
  identical to the fix another slice already prepared, and the rebuilt
  `src/app.js` is byte-identical to it.
