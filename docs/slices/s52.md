# Slice s52 — class `_q` (CM5-style editor facade over CM6)

## Items

| name | kind | bytes | classification | status |
|------|------|-------|----------------|--------|
| `_q` | class-iife | 15701 | application code (editor adapter) | replaced |

`_q` is the CodeMirror-5-compatible facade the bundle wraps around each CM6
`EditorView`. It is instantiated once per vim-mode input handler
(`this.cm = new _q(view)`), exposed as `window.CodeMirrorAdapter`, and handed
to `initVimMode(_q)`. It is application glue, not a third-party library:
CodeMirror 6/Lezer internals and the small app-scope helpers it calls
(position conversion, event trio, indent commands, bracket matching, the vim
search query, bookmark marks, StringStream, Pos, ...) stay inherited and are
reached lazily through `env()`.

## What was done

- `src-app/s52-cm5-adapter.js` — own readable implementation
  (`s52Cm5Adapter` factory, manifest `classes` entry). Returns the constructor
  function itself because `_q` doubles as a namespace (`_q.Pos`,
  `_q.commands`, `_q.keys`, `_q.signal`, `_q.on/off`, `_q.findMatchingTag`,
  `_q.findEnclosingTag`, `_q.isWordChar`, `_q.isMac`, `_q.StringStream`,
  `_q.addClass/rmClass`, `_q.e_preventDefault/e_stop`, `_q.lookupKey`,
  `_q.keyName`).
- All 62 prototype methods of the original are re-implemented with the same
  names and observable behaviour: dialogs/notifications, `on/off/signal`
  event plumbing, `{line,ch}` <-> offset conversion, folds, selections,
  get/set line & range & value, bookmarks, CM5 overlays backed by the vim
  search state, `getSearchCursor` (backward chunked scan + forward match,
  `replace`), `moveByChar`/`findPosV`/`charCoords`/`coordsChar` (incl. the
  metadata-pane `focusBefore`/`hitSide` edge cases), scroll/size helpers,
  the `curOp` change/cursorActivity batching in `onChange`,
  `onSelectionChange`, `operation`, `onBeforeEndOperation` (incl. the
  vim fold re-assert), `moveH`, options, `getTokenTypeAt`,
  `overWriteSelection`, multi-select (`forEachSelection`,
  `virtualSelectionMode`) and `hardWrap`.
- Statics match the original exactly (verified against `git show ca5acac`).
- 40 new `envBind` names (`$q`, `pe`, `ne`, `Bq`, `Fq`, `Nq`, `jq`, `qq`,
  `zq`, `Vq`, `Hq`, `Xq`, `Gq`, `Kq`, `Qq`, `Yq`, `tj`, `uB`, `yB`, `UR`,
  `Wq`, `Vd`, `Zq`, `Jq`, `Rq`, `yp`, `np`, `Gp`, `jp`, `PR`, `LR`, `aN`,
  `oN`, `PF`, `TF`, `SR`, `Oq`, `AR`, `Uq`, `Nd`, `eP`, `W$`, `$I`, `_o`).
- Two `patches` entries fix pre-existing wrapper bugs the facade exposed:
  `qq` and `zq` were variadic via `arguments` and the generated wrappers
  dropped handler/signal args (broke vim `cursorActivity`/`change` delivery).
