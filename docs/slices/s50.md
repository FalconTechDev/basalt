## Runtime bugs fixed while verifying (outside the slice, minimal patches)

Verification of `H4` requires opening a `.base` file, which exposed four
pre-existing bugs in already-merged own code:

- `src-app/s26-bases-controller.js` — `runQuery` restarted the whole query on
  the *first* encounter of the local file: the `ctx.local` getter sets
  `localUsed` on every access, so the added `ctx.localUsed` check in the
  first-visit branch always fired → infinite re-scan (100 % CPU, renderer
  hung). Restored the original `ca5acac` semantics: first sighting only marks
  `done`; regeneration happens on a *repeat* sighting.
- `src-app/s06-properties.js` — the `text` property option called the
  `TextValue` widget without `new` (every sibling option uses `new`), so
  `this` was `undefined` and cell rendering threw inside bases table cells.
- `src-app/s22-views.js`, `src-app/s24-filter.js` — four `new env().X(...)`
  sites missed the `new (env().X)(...)` convention (commit 566709e): they
  parsed as `(new env()).X(...)`, a plain method call on the env object, so
  the combobox/search constructors ran with `this === env` and returned the
  host object (`onOpen is not a function` in the bases filter editor).
- `src-app/s24-filter.js` — `FilterStatement.serialize` crashed with
  `Cannot read properties of undefined (reading 'funcName')` when the operator
  dropdown had no items (see known issue below); added an early `""` return
  for a missing operator value, matching the existing `!lhsId` guard.

## Known issue found (not fixed — outside slice)

Per-type formula methods appear broken bundle-wide: `mockContext.evaluateIdent`
returns `NullValue` for every method call (`"abc".contains("b")`,
`file.file.hasLink()`, `"".isEmpty()`) while globals (`now()`, `today()`) and
plain idents work. Consequence: `FilterStatement.updateOperators()` yields an
empty operator list for `file`-typed lhs values, so the filter editor's
operator dropdown stays empty and method-based filters likely mis-evaluate.
Root cause is in the s08 value/registry or s09 formula-call path — flagged
for the owner; reproduces on `main` independent of this slice.
