## Behaviour differences

- `OQ` (`s09PublishGraphData`): the original drove an async batched iterator (`kb`/`Cb`)
  over cache keys; the own version iterates `Object.keys` directly — same order, same
  result, no batching (batching was only a scheduling detail).
- Publish link-hover state (`XQ`/`$Q`/`ZQ`/`JQ`) is mirrored inside the own module; the
  app-scope vars still exist (bound to the same arrays/constants) for any inherited caller.
- `dQ`/`VY` defaults: the original built the defaults object with a comma-sequence of
  computed-key assignments; the own `s09PublishDefaults()` returns the identical object and
  the declarator replacement still assigns `VY` so both names resolve to it.

## Infrastructure changes supporting this slice

- `build-app.mjs` now emits `envBind` entries as **lazy getters** — own declarator/class
  factories run while the bundle is still evaluating, so eager evaluation hit TDZ errors on
  late-bound names (`electronWindow` etc.).
- `src-app/env.js` `env()` resolves names through the bound thunk on every read.
