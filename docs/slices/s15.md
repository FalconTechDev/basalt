## Build-system change

`build-app.mjs`: `envBind` manifest entries are now emitted as lazy getters instead of eager `const`
initializers. Own class factories call `env()` while the bundle is still initializing, before late-bound
names like `electronWindow` exist; eager evaluation crashed bundle init. Getters preserve semantics —
`env()` still resolves the same application-scope binding, just on first access.

  whether the title blur fires before the test's deletes.
