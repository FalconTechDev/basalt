## What this slice actually did

All 14 items were already replaced by merged slice **s26** (manifest `classes` +
`declarators` entries, own modules `src-app/s26-bases-*.js`). Slice s43 verified
each mapping against the base bundle (`git show ca5acac:src/app.js`), confirmed the
spliced names in the rebuilt `src/app.js`, and fixed two merge artifacts that kept
`node build-app.mjs` / `--check` failing for every agent:

1. Removed the stale `manifest.patches` entry for `P5` (canvas FileNode). `P5` is now
   the own ES6 class `defineS33CanvasFileNode`; the ES5-subclass patch text can never
   match again (s32's commit already noted "P5 patch dropped" but the entry survived
   a merge).
2. Removed three stale `declarators` entries (`Oz`, `Nz`, `Bz`) that duplicated
   slice s22's `classes` entries for the same originals (weak-map box/fallback and
   worker channel). Both slices implemented equivalent code; s22's class form is what
   the bundle builds, and the leftover declarator entries made `--check` fail with
   "differs from the recorded original".

After that `node build-app.mjs` rebuilt `src/app.js` (1161 wrappers, 28 newly
spliced — the pending s26-era manifest entries that had never been built into the
bundle) and `node build-app.mjs --check` passes.
