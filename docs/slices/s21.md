## Behaviour notes

- Faithful quirks preserved: `hO`/`pO` report `type:"datetime"` (the date widget included), number
  widget restores the last *committed* value on Escape (the closure variable is mutated by commit),
  `DO.updateInstructions` renders the manager instructions and then unconditionally re-renders the
  two static ones (the second `renderInstructions` call empties the element first — net effect is the
  static pair, same as shipped), `TextValue.onFocus` maps position → collapse flag exactly like the
  original IIFE (`start`→true, `end`→false, otherwise undefined).
- `_I`/`YI` `selectSuggestion` call `close()` before the context check, matching the original.
- `MultiSelect` is a plain constructor-function class (the original IIFE takes no base); every other
  widget derives through `inherit()` from `iO`/`uO`/`SI`/`NI`/`nb`/`MI` equivalents exposed via
  `__basaltHost`/`env()`.
