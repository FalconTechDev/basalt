## Build fix landed in this slice

`build-app.mjs` now emits `envBind` values as lazy getters
(`get name(){return name}`) instead of an eagerly evaluated object literal.
The eager form crashed at bundle eval whenever an own module read `env()`
before `attachElectron` ran (`electronWindow` is only defined afterwards).
Own modules also expose cross-factory classes through module-level `let`
bindings (`S13TableRow`, `S13CanvasSelection`, ...) populated inside each
factory — an undeclared `S13CardsItem` assignment was missing its `let` and
has been fixed.
