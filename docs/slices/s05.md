## Build-system change

`build-app.mjs` now emits each `envBind` name as a **lazy getter *and* setter**
(`get x(){return x},set x(v){x=v}`) instead of an eager property. Previously the
thunk evaluated every bound name on each `env()` call, so any own code touching
`env()` during bundle init crashed on late-bound globals (e.g. `electronWindow`).
Setters let own code write shared flags (`env().kD = …` in `s05CheckFilePermissions`).
