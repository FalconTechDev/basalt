| `ym` | function | 15,562 | app code (locale display-name lookup used by the settings language pickers via `env().ym`) | replaced by `s65LocaleName` in `src-app/s65-locale-name.js` (manifest `entries`) |

`ym(locale)` splits a locale tag on `-` and returns a readable name: ISO 639-1 /
ISO 639-2/3 language name plus the ISO 3166-1 alpha-2 region name in parentheses,
with any further subtags appended verbatim in parentheses. Single-part tags also
fall back to the country table (so `US` -> `United States`). The three lookup
tables are factual CLDR-derived name data, re-emitted as readable own objects;
the logic is a clean-room rewrite. No host access needed (self-contained).
