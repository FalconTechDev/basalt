`H0` is the workspace root: constructor/field setup, global listeners
(resize, popstate, history, copy/paste/cut, statusTap), file/files/menu
handlers, editor-menu handlers, quit handler, ~40 command registrations,
`obsidian://` protocol handlers (`open`, `search`, `new`, `show-plugin`,
`show-theme`, `show-release-notes`, `debug-info`, `publish-sites`,
`sync-setup`, `vault-setup`, `hook-get-address`), mobile back-button and
swipe handling, iOS css-change bridge, hover-link source registration and
the `CodeMirror.getMode` deferred-syntax-highlight patch.

## What was done

- `src-app/s48-workspace.js` — own factory `s48Workspace(host)` replacing the
  whole class-IIFE init (`classes` manifest entry). Returns a constructor
  function `Workspace` (ES5-callable via `env().VT.call(this)`, linked with
  `inherit`), attaches the 81 already-own prototype methods from
  `workspace.js`, and defines the `initialized` / `activeEditor` accessors.
  All app-scope names are read lazily through `env()`; own-module helpers
  through `host` (`MarkdownView`, `codeMirrorCompat`, `onSwipe`).
- The 81 prototype methods were already replaced earlier at `methods` level
  (`ws*` in `src-app/workspace.js`); the class entry coexists with them —
  `build-app.mjs` verifies the init against the base text with those method
  nodes rewritten to `__basaltOwn.*` wrappers (same pattern as `Tte`/`mI`).
- `envBind` gained the names the constructor body reads: `jg R0 Sv tE oP
  Cc rg Hm Rg B0 P0 f0 BX OX pI dI wJ fz ry`.
